# Comprehensive Test Suite

90%+ code coverage testing framework with unit, integration, edge case, security, and performance tests.

## Quick Start

```bash
# Run all tests
pnpm test

# Run specific test category
pnpm test:unit          # Unit tests only
pnpm test:integration   # Integration tests
pnpm test:edge-cases    # Edge cases & concurrency
pnpm test:security      # Security & injection tests
pnpm test:performance   # Load & performance tests

# Watch mode (rerun on file changes)
pnpm test:watch
pnpm test:unit:watch

# Coverage report
pnpm test:coverage
```

## Test Isolation

Each test file uses a unique prefix generated by `uid()`:

```typescript
const PREFIX = uid("feature-name");

after(async () => {
  // Clean up test data
  await purgeWorkspacesByNamePrefix(PREFIX);
});
```

This ensures:
- ✓ Tests don't interfere with each other
- ✓ Tests can run concurrently
- ✓ Automatic cleanup after tests
- ✓ No shared state between runs

## Writing Tests

### Unit Test Template

```typescript
import test from "node:test";
import assert from "node:assert/strict";
import { functionToTest } from "../../lib/module";

test("functionToTest", async (t) => {
  await t.test("does expected thing", () => {
    const result = functionToTest(input);
    assert.equal(result, expected);
  });
});
```

### Integration Test Template

```typescript
import test, { after } from "node:test";
import assert from "node:assert/strict";
import { pgPool } from "../../lib/db";
import { uid, purgeWorkspacesByNamePrefix } from "../helpers/pg";

const PREFIX = uid("feature");

after(async () => {
  await purgeWorkspacesByNamePrefix(PREFIX);
});

test("Feature Integration", async (t) => {
  await t.test("workflow works end-to-end", async () => {
    const pool = pgPool();
    // ... test code
  });
});
```

## Running Tests

### All Tests (Serial)
```bash
pnpm test
```
Runs all tests with 1 concurrent test (for DB isolation).

### Tests in Parallel
```bash
pnpm test test/unit/*.test.ts
```
Unit tests have no DB dependencies, safe to parallelize.

### Watch Mode
```bash
pnpm test:watch
```
Rerun tests when files change. Useful during development.

### Specific Test
```bash
pnpm test --grep "cannot inject via workspace name"
```

### With Verbose Output
```bash
NODE_DEBUG=* pnpm test test/security/*.test.ts
```

## Troubleshooting

### "ECONNREFUSED localhost:5432"
Database not running or not accessible.

```bash
# Start Postgres (Docker)
docker run -d -p 5432:5432 \
  -e POSTGRES_PASSWORD=postgres \
  postgres:16

# Or via local installation
psql --version  # verify installed
pg_isready      # check if running
```

### "Timeout of 30000ms exceeded"
Test taking too long. Check:
1. Database connection speed
2. System load
3. Test complexity
4. Concurrent test limit

### "Duplicate key value violates unique constraint"
Test data not cleaned up. Fix:

```bash
psql $DATABASE_URL << EOF
DELETE FROM workspaces WHERE name LIKE 'test_%';
DELETE FROM users WHERE email LIKE 'test_%';
EOF
```

### "Test file not found"
Create the directory first:

```bash
mkdir -p test/unit test/integration test/security
```
